# Observability

Metrics: processed articles, entities, aliases, mentions, relations, claims, events, unresolved queue, confidence, conflicts, AI calls/tokens/cost, cache, escalation, retries, claim loss, API latency/errors, read-model lag and backfill progress.

Every run/step/request has correlation identity. Logs exclude passwords, reset tokens, API keys and raw sensitive provider payloads.

Alerts: budget exceeded, conflict spike, queue growth, stale claims, repeated schema failures and entitlement errors.
