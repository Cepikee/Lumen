# Confidence System

A confidence nem pusztán AI által adott szám. Jelek: extraction confidence, match quality, evidence count, independent source count, consistency, recency, conflict status.

A score jelentése és thresholdja objektumtípusonként dokumentálandó. Nem állítható hamis matematikai pontosság.

Confidence history append-only: előző/új érték, indok, model/rule version, evidence delta.
