# Context Generation

A context kérdései: mi történt, mi vezetett idáig, kik érintettek, mi változott, miért fontos, milyen korábbi eventhez kapcsolódik, milyen eltérő állítások vannak.

Generálás read modelből és claim/evidence inputból történik. Minden fontos mondat evidence reference-t kap.

AI csak összefoglaló formázást végezhet; evidence nélküli állítás nem jelenhet meg verified tényként. Cache és schema version kötelező.
