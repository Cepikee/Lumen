# Source Comparison

Egy event/topic forrásainak összevetése: ki publikálta először, közös állítások, source-specifikus állítások, eltérések és időbeli változás.

A comparison claim/evidence alapon működik, nem source trust shortcut alapján. Reported, inferred, disputed és verified címkék külön jelennek meg.

Deterministic ordering: published time, source identity, claim key. Pagination és missing source explicit.
